# DiffGit

## Setup
```bash
# Create and activate virtual environment (optional but recommended)
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate

# Install dependencies
pip install flake8
```

## Usage

```bash
# Run the main code
python code.py

# Process the code
python code_processor.py
```
